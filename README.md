# 🤖 ChatGPT Proxy (Arabic RTL)

بروكسي ويب عربي لواجهة ChatGPT مع لوحة إدارة، مبني على Next.js 14 ويعمل على Vercel.

## ✨ المزايا
- واجهة عربية RTL كاملة مع محادثات متعددة الأدوار (multi-turn).
- اختيار النموذج (GPT-4o / 4o-mini / GPT-4 / O1 / O3-mini).
- استيراد كوكيز ChatGPT مباشرة بصيغة JSON من إضافة EditThisCookie.
- تحديث تلقائي لـ Access Token عند كل رسالة + إعادة محاولة عند 401/403.
- بث مباشر للردود (SSE streaming) مع زر إيقاف.
- حفظ المحادثة محلياً في المتصفح (localStorage).
- اختيار نموذج افتراضي، مفتاح API اختياري لحماية الواجهة.
- دعم Supabase لحفظ الإعدادات عبر إعادة النشر (اختياري).
- نقطة نهاية متوافقة جزئياً مع OpenAI: `/api/v1/chat/completions`.
- Cron endpoint لتجديد التوكن يومياً.

## 🚀 النشر على Vercel
1. ارفع المشروع على GitHub ثم استورد منه في Vercel، أو انشر مباشرة بـ `vercel`.
2. (اختياري) أضف متغيرات البيئة في Vercel:
   - `JWT_SECRET` = أي نص طويل عشوائي.
   - `SUPABASE_URL` + `SUPABASE_SERVICE_ROLE_KEY` (لحفظ دائم).
   - `CRON_SECRET` (لحماية endpoint التجديد).
3. بعد أول زيارة للموقع سيُطلب منك اختيار كلمة مرور للإدارة.
4. ادخل على `/admin` → أداة الاستيراد → الصق كوكيز chatgpt.com → احفظ → سيُحدَّث التوكن تلقائياً.
5. ابدأ المحادثة من الصفحة الرئيسية.

## 🗄️ إعداد Supabase (اختياري)
انظر `SUPABASE_SETUP.md`.

## ⏲️ تجديد التوكن يومياً (اختياري)
على استضافة Namecheap cPanel (أو أي Cron خارجي):
```
GET https://your-app.vercel.app/api/cron/refresh?secret=CRON_SECRET
```
الجدول: `0 0 * * *` (يومياً منتصف الليل).

## 📝 ملاحظات
- بدون Supabase، الإعدادات تُحفظ في الذاكرة فقط وستفقد عند إعادة النشر.
- كوكيز ChatGPT صلاحيتها حوالي أسبوعين إلى شهر، ستحتاج لتحديثها دورياً.
- إذا ظهر خطأ "انتهت صلاحية الجلسة"، حدّث الكوكيز من لوحة الإدارة.
